# 央企基本信息知识图谱

双击 `index.html` 即可离线打开网页，无需安装依赖或启动服务器。

## 当前数据范围

网页和配套 Excel 由 `央企名单.xlsx` 的 98 家集团级记录，以及 `outputs/央企名单_大数据平台调研.xlsx` 的逐行平台调研结果生成。平台调研包含 36 条“已披露”、21 条“建设中”、4 条“待核验”和 37 条“未检索到”记录，且每条均保留来源标题、URL、访问日期、可信度和备注。

源数据暂未提供二级/三级组织关系、总部所在地、经营财务、上市平台、来源网址和 SAP/HANA 明细，因此网页会显示“待补充”，不会生成虚构节点或关系。

## 后续补充二三级数据

请参考 `央企二三级单位组织架构.xlsx` 的“二三级导入模板”填写企业 ID、层级、上级企业 ID、上级企业、所属集团等字段。重新运行 `scripts/build-data.mjs` 后，图谱会按真实父子关系生成逐级展开和组织路径高亮。

## 交互说明

- 单击企业：查看右侧详情、平台结论和证据来源。
- 双击集团或二级单位：展开/收起下一级及已核验的大数据平台节点。
- 滚轮：缩放；拖动空白处：平移；拖动节点：调整节点位置。
- 左侧支持名称/属性搜索、层级、行业及地区多选筛选。
- 可切换图谱视图与表格视图；右上工具可展开、收起、适应和恢复视图。
